Каталог шин и дисков — продающая презентация
==============================================

Хостинг НЕ нужен. Колода — оффлайн HTML (index.html + deck.css + deck.js).

1. Откройте файл index.html двойным кликом
   или через «Открыть с помощью» → Chrome / Edge / Firefox.

2. Управление:
    - колесо мыши, трекпад и жест вверх-вниз (кадр на весь экран)
    - стрелки ↓ ↑, ← →, Space, PageDown, PageUp, Home, End
    - кнопки вверх/вниз и точки внизу экрана

3. Демо каталога (нужен интернет):
   https://iscander-b10.github.io/tyres_discs/demo

4. Контакты для связи — на последнем слайде «Следующий шаг»:
   Telegram @Iscander_b10, телефон +7 (965) 309-39-32.

5. Содержание колоды (8 слайдов):
   - Что это — единый каталог шин и дисков под магазин
   - Пять преимуществ: меньше рутины (единый поиск), полнее выбор,
     в кадре ваш магазин, с любого устройства, база для индивидуальных условий
   - Два режима работы — менеджер (служебные данные) и клиент (цена и остаток)
   - Следующий шаг — проверка на реальном запросе, ссылка на демо, контакты

6. Печать → Сохранить как PDF (тёмная колода, 8 страниц):
   Откройте index.html в Chrome или Edge. Ctrl+P (Windows) / Cmd+P (macOS).
   В диалоге печати:
   - Принтер: «Сохранить как PDF» / «Save as PDF» / «Microsoft Print to PDF»
   - Ориентация: альбомная
   - Поля: нет (или «По умолчанию» — поля страницы задаёт колода)
   - Колонтитулы браузера: выключить
     Chrome: Ещё настройки → снять «Колонтитулы»
     Edge: Дополнительные параметры → снять «Колонтитулы»
   - Фоновая графика: включить
     Chrome: Ещё настройки → «Фоновые графические объекты»
     Edge: Дополнительные параметры → «Фоновая графика»
   Сохраните файл. Должно получиться 8 альбомных страниц — по слайду на страницу,
   без пустой десятой и без кнопок навигации. Если фон белый — вернитесь
   в диалог и включите фоновую графику.
