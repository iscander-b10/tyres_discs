Каталог шин и дисков — продающая презентация
==============================================

Хостинг НЕ нужен. Колода — оффлайн HTML (index.html + deck.css + deck.js).

1. Откройте файл index.html двойным кликом
   или через «Открыть с помощью» → Chrome / Edge / Firefox.

2. Управление:
    - колесо мыши, трекпад и жест вверх-вниз (кадр на весь экран)
    - стрелки ↓ ↑, ← →, Space, PageDown, PageUp, Home, End
    - кнопки вверх/вниз и точки внизу экрана

3. Демо каталога (нужен интернет):
   https://iscander-b10.github.io/tyres_discs/demo

4. Контакты для связи — на последнем слайде «Следующий шаг»:
   Telegram @Iscander_b10, телефон +7 (965) 309-39-32.

5. Содержание колоды (9 слайдов):
   - Что это — единый каталог шин и дисков под магазин
   - Пять преимуществ: меньше рутины (единый поиск), полнее выбор,
     в кадре ваш магазин, с любого устройства, опора для скидки
   - Два режима работы — менеджер (служебные данные) и клиент (цена и остаток)
   - Подписка — прозрачная модель рабочего каталога
   - Следующий шаг — проверка на реальном запросе, ссылка на демо, контакты
