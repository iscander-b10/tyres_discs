Каталог шин и дисков — продающая презентация
==============================================

Хостинг НЕ нужен.

1. Откройте файл index.html двойным кликом
   или через «Открыть с помощью» → Chrome / Edge / Firefox.

2. Управление:
   - стрелки ← → на клавиатуре
   - кнопки внизу экрана
   - точки слайдов
   - свайп влево/вправо на телефоне или планшете

3. Демо каталога (нужен интернет):
   https://iscander-b10.github.io/tyres_discs

4. Перед показом клиентам замените контакты на слайде «Следующий шаг»
   в index.html (поиск: @ваш_telegram).
