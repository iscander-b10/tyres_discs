Рабочее место, которое помогает команде вести подбор без лишних вкладок

Ваши поставщики, ваши цены и корзина в одном окне браузера.

Каталог собирает данные. Сотрудник применяет свой опыт и выбирает, что предложить клиенту.

Каталог вырос из пилота с реальным магазином и собран вокруг повседневной работы команды.

Пока клиент ждёт в зале

Полный ответ приходится собирать из нескольких кабинетов поставщиков

Один запрос — несколько повторений

Размер, бренд, цену и остаток приходится заново вводить и сверять в разных системах. Это отнимает внимание от разговора с клиентом.

сложность процесса

Подходящий вариант может остаться между вкладками

Остатки и цены меняются у каждого поставщика отдельно. Невозможно держать в памяти весь ассортимент и одновременно вести разговор с клиентом.

Рабочему месту нужен отдельный режим показа: без чужих витрин и служебных цен.

Меньше рутины

Один запрос вместо повторного поиска у каждого поставщика

  • Один поиск по всем подключённым поставщикам — без переключения вкладок и повторного ввода размера.
  • Шины и диски в одном каталоге. Для каждой категории — своя форма и подходящие фильтры.
  • Прайсы и остатки обновляются автоматически по настроенному расписанию.

Меньше переключений — больше внимания клиенту.

Больше вариантов в одном поиске

Каталог проверяет всех подключённых поставщиков одновременно

Невозможно держать в голове меняющиеся остатки и ассортимент каждого поставщика. Общий поиск показывает подходящие позиции в одном окне.

Сотрудник сравнивает варианты и выбирает лучшее решение для клиента. Этот рабочий сценарий стал одной из задач пилота с реальным магазином.

Данные для разговора о цене

Три ценовых ориентира в карточке — расчёт перед глазами

  • B2B Закупочная цена, которую передал поставщик.
  • Интернет цена Если поставщик передал цену со своего сайта.
  • Цена Уже по согласованным правилам наценки магазина.

Сотрудник видит ориентиры для уверенного разговора с клиентом. В режиме показа остаётся только цена магазина.

Комплект на одном экране

Все суммы по комплекту перед глазами до решения о скидке

  • По каждой позиции видны ценовые ориентиры и сумма магазина. В итогах — цена комплекта и служебная сумма B2B.
  • Каталог даёт цифры, на которые можно опереться. Скидку и итоговое предложение определяет сотрудник.

Корзина помогает собрать предложение, но не оформляет заказ и не принимает оплату. Для показа клиенту служебные данные скрываются.

Разговор от имени магазина

Клиент видит предложение вашего магазина — без служебных данных

Рабочий режим

Полная картина для сотрудника

  • B2B: закупка
  • Интернет цена: с сайта поставщика
  • Цена: магазина
  • Поставщик

Режим клиента

Готовое предложение магазина

  • B2B и поставщик скрыты
  • Клиент видит цену магазина
  • Подбор остаётся на одном экране рядом с клиентом

Один переключатель скрывает служебные данные, не меняя собранную корзину. В центре разговора остаются ваши цены, ваш подбор и опыт сотрудника.

Инструмент рядом с клиентом

Опыт сотрудника — в центре, все данные — под рукой

Рабочий браузер на удобном устройстве

Каталог открывается на телефоне, планшете или компьютере — там, где сотрудник ведёт разговор с клиентом.

  • Каждый ведёт свой подбор и собирает корзину на своём устройстве.
  • Нужные данные остаются рядом у стойки или во время разговора по телефону.
  • Каталог снимает рутину. Опыт, разговор с клиентом и решение по цене остаются за человеком.
