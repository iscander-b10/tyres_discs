# Как пользоваться учебником

Ivanor — React-приложение на Create React App и Ant Design для работы с каталогом шин и дисков нескольких поставщиков. Каталог подготавливается в Yandex Cloud, загружается в браузер как версионированный snapshot и сохраняется в IndexedDB. Авторизация и корзина работают локально в браузере в рамках текущей модели проекта.

Документация предназначена для начинающего frontend-разработчика, которому важно не только увидеть имя файла, но и понять, кто его вызывает, какими данными он владеет и что произойдёт при ошибке или смене workspace.

## Запуск сайта документации

```bash
npm install
npm run docs:dev
```

После запуска откройте `http://localhost:5173/`. Основное CRA-приложение может одновременно работать на `http://localhost:3000/tyres_discs`: порты и сборки разделены.

Для проверки production-сборки документации:

```bash
npm run docs:build
npm run docs:preview
```

Preview по умолчанию доступен на `http://localhost:4173/`.

## Архитектурные страницы и страницы модулей

Архитектурная страница объясняет связи и границы нескольких модулей: например, путь данных от Cloud Function до IndexedDB. Страница компонента или функции разбирает один контракт: props, параметры, состояние, side effects, ошибки и вызывающие стороны. Ссылки между ними позволяют идти сверху вниз — от системы к строкам реализации — без копирования одного объяснения в разные разделы.

```mermaid
flowchart LR
  A[Обзор и контекст] --> B[Границы и слои]
  B --> C[Состояние и потоки]
  C --> D[Пользовательский сценарий]
  D --> E[Модуль и тесты]
```

## Факты, планы и текущее состояние

- **Фактическое поведение** подтверждается кодом и тестами.
- **Планируется** означает будущую страницу или изменение, которого ещё нет в production-коде.
- **Заготовка** означает, что маршрут и назначение страницы готовы, но подробное объяснение ещё не проверено целиком.
- [План документации](/documentation-plan) хранит полное покрытие и порядок работы.
- [Статус документации](/documentation-status) показывает, какие страницы уже проверены.

Документация не публикуется вместе с GitHub Pages-приложением и не меняет его production-сборку.
